# Pet Poll Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun survei pet friendly untuk tenant dengan dropdown pencarian database, keputusan izin pet, konfirmasi, rekap admin, dan pengaturan dinamis.

**Architecture:** Tabel `pet_polls` untuk konfigurasi survei dan `pet_poll_responses` dengan unique constraint per tenant. `PetPollService` memegang logika bisnis dan query. Dua controller tipis untuk publik dan admin. Halaman publik standalone dengan CSS/JS vanilla, admin memakai template backend Bootstrap 5.

**Tech Stack:** Laravel 12, PHPUnit 11, Blade, Bootstrap 5 (admin), CSS & JS vanilla (publik), tanpa dependency baru.

**Spec:** Desain yang disetujui pada sesi 19 November 2026: konsep Papan Nama Tenant, dial ENERGY 2 / RHYTHM 1 / MOTION 1, copy bahasa Indonesia tanpa em dash.

## Global Constraints

- Semua copy UI dalam bahasa Indonesia, persis seperti spesifikasi.
- Tidak ada karakter em dash di kode, komentar, atau copy.
- Tidak ada dependency baru.
- Waktu disimpan dalam UTC, ditampilkan dalam WITA (Asia/Makassar).
- Hanya tenant dengan is_active = true dan type = tenant yang bisa dipilih.
- Satu tenant hanya punya satu baris jawaban per survei. Kiriman ulang memperbarui baris yang sama.
- Palet publik: #F4F0E3, #FFFDF7, #1A1A1A, #2C5F5D, #1A3A38, #5A6A68, #A67C3D, #7A5A2E, #DCD4BF.
- Semua kontrol interaktif bisa dioperasikan dengan keyboard dan punya fokus yang terlihat.
- Tidak ada angka contoh, testimoni, atau klaim yang dikarang di UI.
- Tidak ada perubahan pada halaman publik lain.

## Review Focus

1. Kiriman ganda atau bersamaan untuk tenant yang sama: database constraint mencegah duplikasi, baris diupdate.
2. Tenant membuka form setelah tenggat: state ditutup tampil, submit ditolak.
3. Pencarian tenant dengan karakter sedikit, kosong, nama berapostrof, dan hasil dibatasi 20.
4. Pertanyaan atau cakupan pet diubah setelah ada jawaban: ditolak dan terkunci.
5. Form diakses tanpa JS dan di layar sempit (320px): tetap bisa dikirim dan tidak ada overflow horizontal.
